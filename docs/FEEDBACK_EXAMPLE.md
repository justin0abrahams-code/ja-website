# Example Website Feedback

Use one GitHub Issue for each distinct change. A useful request describes the current result, the desired result, and how everyone will know the work is complete.

## Example completed issue

**Title**

```text
[Website feedback] Clarify delivery coverage on the FAQ page
```

**Feedback type**

```text
Content change
```

**Page or location**

```text
FAQ page — Delivery and setup section
http://localhost:3000/faq/
```

**What needs to change?**

```text
The current answer says delivery is available across North Georgia, but it does
not tell customers that travel outside the normal service area may still be
possible. Customers may leave without asking.
```

**Desired wording or result**

```text
Replace the answer with:

"Delivery, setup, and pickup are available throughout our normal North Georgia
service area. Events farther away may still be possible depending on the date
and equipment requested, so include the venue address in your quote request."
```

**Screenshot**

```text
Screenshot attached with the current paragraph highlighted.
```

**Device and browser**

```text
Windows 11, Microsoft Edge, desktop window
```

**Priority**

```text
Normal
```

**Acceptance criteria**

```text
- The new answer appears in the delivery section of the FAQ.
- The wording is readable on desktop and mobile.
- "North Georgia" remains capitalized.
- The answer links or directs customers to the quote request without displaying pricing.
```

This example is actionable because it identifies one page, supplies exact approved copy, explains the reason, and defines the finished result.
